## 🚀 Featured Project

### ☕ [Beanote](https://github.com/HaeseokPark/beannote): 원두 취향 추천 + 시음 노트
> 개인 프로젝트 · 2026.10 – · **기획서 작성부터, 추천 품질을 기준선과 비교해 숫자로 검증**

마신 커피의 맛을 기록하면 취향을 숫자로 보여주고, 다음에 마실 원두를 **이유와 함께** 추천하는 서비스입니다.

| 고민한 문제 | 해결 |
|---|---|
| 가상 데이터로 평가하면 콘텐츠 기반이 당연히 이기는 순환 평가 | 벡터 밖 숨은 요인을 넣은 가상 데이터 + 시간순 홀드아웃, **인기순 대비 NDCG@10 +111%** |
| 협업 필터링이 예상보다 강하게 나온 결과 | 숨은 요인 제거 실험으로 **코사인이 "가운데 선호"를 표현하지 못하는 구조적 원인** 확인·기록 |
| 평점을 짜게/후하게 주는 사람의 취향 비교 | (평점 − 본인 평균) × 주간 감쇠로 **평점 기준 보정**, 규칙을 단위 테스트로 고정 |
| LLM 없이 추천 이유 만들기 | 유사도를 **차원별 기여도로 분해** → 템플릿 문장 (재현 가능 · 테스트 가능) |
| 추천 API 응답 속도 | 원두·사용자 1,000명 기준 **p95 65.6ms**, 캐시는 트랜잭션 커밋 후 무효화 |

`Java 21` `Spring Boot 4` `Spring Security` `MySQL 8` `Flyway` `Caffeine` `React 19` `TypeScript` `GitHub Actions` `테스트 115개`

### 🎵 [SoundMap](https://github.com/HaeseokPark/Soundmap): 위치 기반 음악 소셜 플랫폼
> 개인 프로젝트 · 2026.09 – · **기획부터 배포까지 혼자, 실제 운영 중** → [soundmap.duckdns.org](https://soundmap.duckdns.org)

지금 듣는 음악을 지도에 공유하고, 취향이 비슷한 주변 사람을 찾아 대화하는 서비스입니다.

| 고민한 문제 | 해결 |
|---|---|
| MySQL 반경 검색이 전체 스캔 | 격자 좌표 복합 인덱스로 후보 압축 → haversine 재검증, **2단계 조회** |
| 동시 전송 시 안 읽은 메시지 카운터 유실 (lost update) | 쓰기 잠금 적용, **20건 동시 전송에서 정확히 20** 검증 |
| 가수를 많이 고른 사람이 유리한 취향 점수 | **자카드 유사도** (가수 70% + 장르 30%) |
| 마커 수만큼 늘어나는 재생곡 쿼리 | IN 절 일괄 조회로 **N+1 제거** |

`Java 21` `Spring Boot 4` `Spring Security 7` `MySQL 8` `WebSocket/STOMP` `Web Push` `React 19` `AWS Lightsail` `nginx`

### 🚶 [FeelRoute](https://github.com/HaeseokPark/feelRoute): 나에게 편한 보행 경로 비교
> 개인 프로젝트 · 2026.08 · 포항 북구 생활권 보행 그래프(구간 20,034) + 고도 데이터 · 테스트 32개

최단 경로 옆에 계단·오르막·횡단보도를 덜 지나는 대안을 보여주고, **몇 m 더 걷고 상승고도가 몇 m 줄었는지** 근거를 함께 제시합니다.

| 고민한 문제 | 해결 |
|---|---|
| 우회 한도 안의 저비용 후보가 일반 A*에서 버려짐 | (거리, 비용) **비지배 라벨을 유지하는 다중 기준 탐색** |
| 지도에서 찍은 위치가 선분 중간 | 선분 투영 후 **임시 노드로 분할**, 고도도 해당 부분만 계산 |
| 고도 결측을 평지로 오인 | HGT 직접 해석·보간, 결측·교량·터널은 **"경사 미확인"으로 분리 집계** |
| 사용자 위치 노출 | 경로 계산을 **브라우저 Web Worker**에서 수행, 좌표를 서버로 보내지 않음 |

`TypeScript` `React 19` `Leaflet` `Web Worker` `OpenStreetMap` `SRTM/HGT` `Node test runner`
